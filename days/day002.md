# Day 002 : Temporary User Setup with Expiry

Create a user that stops working by itself on a given date, for a contractor or temporary access.

Connect to the server and become root:

```bash
ssh banner@stapp03
sudo su -
```

Set the expiry at creation time with `-e`:

```bash
useradd -e 2027-03-28 anita
```

Or on a user that already exists, with `-E`:

```bash
useradd anita
chage -E 2027-03-28 anita
```

Check it:

```bash
chage -l anita
# Account expires : Mar 28, 2027
```

The date lives in the 8th field of `/etc/shadow`, stored as a number of days since 1970:

```bash
grep anita /etc/shadow
```

> Lowercase `-e` on useradd, uppercase `-E` on chage. Easy to mix up.

> I was logged in as anita over ssh, then set the expiry from another terminal as root. The open session kept working. The date is only checked when a new session opens, so after `exit` the next ssh was refused.
