# Day 001 : Linux User Setup with Non-Interactive Shell

Create a user that exists on the system but cannot log in.

```bash
sudo useradd -s /sbin/nologin siva
```

`adduser` works too, Debian only, and it asks questions while it runs:

```bash
sudo adduser --shell /sbin/nologin siva
```

`/bin/false` gives the same result but exits silently, **nologin** prints why the login failed:

```bash
sudo useradd -s /bin/false siva
```

Check the last field of `/etc/passwd`:

```bash
grep siva /etc/passwd
```

> Path is `/sbin/nologin` on RHEL, `/usr/sbin/nologin` on Ubuntu. Find it with `cat /etc/shells`.
